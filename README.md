# lgp21-subroutine-manual-english

A LaTeX translation of the Eurocomm LGP-21 manual at https://www.technikum29.de/de/geraete/LGP21/LGP21_PDFs/LGP-21%20Unterprogramm-Handbuch.pdf

This manual describes many of the Eurocomp library programs (available at https://www.technikum29.de/de/geraete/LGP21/LGP21_papertapes/). No current versions of an English version of this manual exist, so I've take the time to brush up my rusty German and work with Google Translate to read, understand, and translate this document.
