\section{Sorting}
\subsection*{SORTING 1 --- L1-10.0}
\addcontentsline{toc}{subsection}{SORTING 1 --- L1-10.0}

\subsubsection*{PURPOSE}
\texttt{L1-10.0} sorts a list of numbers within memory by magnitude (smallest value to largest value) according to a specified mask. The sorted numbers are stored in the same memory region as the unsorted ones, so no additional memory space is required. The mask determines which parts of the words are compared.

The program operates as a subroutine called by a calling sequence from the main program. Upon jumping to the subroutine, the starting address of the numbers to be sorted must reside in the accumulator, and the address of the mask must have been stored in the subroutine. The two locations following the jump instruction must contain the mask and the ending address of the list. Upon returning to the main program, the numbers stand sorted by magnitude (smallest to largest) in the original memory region of the list.

\subsubsection*{STORAGE REQUIREMENTS}
\begin{itemize}
    \item[] \textbf{Memory:} 1 track, 32 sectors (96 words)
    \item[] \textbf{Temporary storage:} sectors 54, 55, 62, and 63 of track 63
\end{itemize}

\subsubsection*{INPUT}
Sequence of input variables:
\begin{enumerate}
    \item $L_1$ Starting address of the numbers to be sorted in decimal track/sector notation.
    \item Arbitrary mask controlling the sorting process, in hexadecimal notation.
    \item $L_2$ Ending address of the numbers to be sorted in decimal track/sector notation.
\end{enumerate}

The mask must not contain a ``1'' in the sign position, as the subroutine ignores the sign of the numbers being sorted. $L_1$ and $L_2$ are inclusive.

Upon jumping to the subroutine, $L_1$ at $q = 29$ must reside in the accumulator. The locations following the jump instruction must contain the mask and $L_2$. The numbers to be sorted must reside in consecutive locations.

The instruction at $\alpha-1$ brings $L_1$ into the accumulator at $q=29$. (Any instruction that achieves this may be used.) The instruction at $\alpha$ stores the address of the mask ($\alpha+2$) in the subroutine. The instruction at $\alpha+1$ effects a jump to $L_0$, the starting address of the subroutine. Location $\alpha+2$ contains the hexadecimal mask. The instruction at $\alpha+3$ contains $L_2$. Location $\alpha+4$ contains the instruction of the main program that is executed first after the subroutine runs.

\subsubsection*{OPERATION}
\begin{enumerate}
    \item \textbf{Execution time:} \\
    Average values:
    \begin{itemize}
        \item 32 words -- 114 sec.
        \item 64 words -- 6 min.
        \item 128 words -- 27 min.
    \end{itemize}
    \item \textbf{Program entry:} \\
    The tape contains the program in two versions:
    \begin{itemize}
        \item[a)] arbitrarily relocatable, hexadecimal, permissible for Program Input 1, and
        \item[b)] arbitrarily relocatable, decimal, in coding sheet format.
    \end{itemize}
    \item \textbf{Required input/output units:} \\
    No input or output units are required.
    \item \textbf{Overflow:} \\
    Ignored upon entry and not reset upon exit.
\end{enumerate}

\subsection*{SORTING 2 --- L1-10.1}
\addcontentsline{toc}{subsection}{SORTING 2 --- L1-10.1}

\subsubsection*{PURPOSE}
\texttt{L1-10.1} sorts one-word or multi-word ``intervals'' [records] within a contiguous memory region by magnitude (smallest value to largest value) according to a designated ``sorting key word'' located within each respective record. Each record can be 1 to 64 words long. An additional memory region is required to temporarily buffer record contents during the sorting process. Sorting occurs relative to an arbitrary mask.

``Sorting 2'' operates as a subroutine called by a calling sequence from the main program. Upon jumping to the subroutine, a key word specifying the number of records to process and the starting address of the first record must reside in the accumulator. Additionally, the calling sequence must supply the ``sorting key word'' position and the mask. Upon returning to the main program, the records stand sorted in the original memory region.

\subsubsection*{STORAGE REQUIREMENTS}
\begin{itemize}
    \item[] \textbf{Memory:} 4 tracks (256 words)
    \item[] \textbf{Temporary storage:} 2 tracks ($L_0 + 0400$ to $L_0 + 0563$, where $L_0$ is the starting address of the subroutine).
\end{itemize}

\subsubsection*{INPUT}
The input consists of three hexadecimal key words supplied by the calling sequence and the record contents to be sorted. The key words are:
\begin{enumerate}
    \item $R$, the number of records at $q = 15$; and $L_1$, the starting address of the first record at $q = 29$.
    \item $N$, the number of words in each record at $q = 15$; and $K$, the position of the sorting key word within a record at $q = 29$. (For example, $K = 3$ at $q = 29$ specifies that the third word of the record is the sorting key).
    \item A mask indicating the bit positions to be compared during sorting.
\end{enumerate}

The number of records sortable in a single run is limited only by available memory space. For $N$ (the number of words per record), the following applies: $1 \le N \le 64$. The mask should not contain a ``1'' in the sign position, as the subroutine ignores the sign of the words during sorting.

The records to be sorted must reside in consecutive locations.

\subsection*{SORTING 4 --- L1-10.3}
\addcontentsline{toc}{subsection}{SORTING 4 --- L1-10.3}

\subsubsection*{PURPOSE}
\texttt{L1-10.3} sorts single-word or multi-word ``intervals'' [records]. In a list of single-word records, every word is treated as a comparison word [key]. In a list of multi-word records, any arbitrary word at the same position across all records can be designated as the comparison key word.

The sorting process can be executed using any of the three following methods:
\begin{itemize}
    \item[\textbf{Method I:}] Sorts the comparison key words by magnitude (smallest value to largest value) and generates a contiguous list of the addresses where these key words are located; i.e., the first location of the new list contains the address of the key word with the smallest numerical value from the original list.
    \item[\textbf{Method II:}] Sorts the comparison key words by magnitude (smallest value to largest value) and creates a contiguous list containing only the sorted key words themselves.
    \item[\textbf{Method III:}] Sorts the comparison key words by magnitude (smallest value to largest value) and generates a new list containing the fully sorted records. With this method, the new sorted list has the exact same length as the original list.
\end{itemize}

\noindent \textbf{Note:} If two comparison key words are identical in magnitude, the first one encountered is treated as though it has the smaller value.

The program is invoked via a calling sequence from the main program. Upon jumping to ``Sorting 4'', the starting address of the parameter list must reside in the accumulator. Upon returning to the main program, the list stands sorted and stored in accordance with the specifications in the parameter list.

\subsubsection*{STORAGE REQUIREMENTS}
\begin{itemize}
    \item[] \textbf{Memory used:} 3 tracks (192 words)
    \item[] \textbf{Temporary storage:} none
\end{itemize}

\subsubsection*{PROGRAM VARIABLES}
The seven program parameters must be specified in the following exact sequence:
\begin{enumerate}
    \item \texttt{bbbb}, the starting address of the unsorted list.
    \item \texttt{aaaa}, the starting address of the memory region where the sorted list is to be stored.
    \item \texttt{nnnn}, the number of records [intervals] in the list, in decimal track/sector notation.
    \item \texttt{wwww}, the number of words per record [interval], in decimal track/sector notation.
    \item \texttt{kkkk}, specifies which word within each record is to be used as the comparison key word.
    \item \texttt{t}, the selection code for the sorting method: 1 for Method I, 2 for Method II, or 3 for Method III.
    \item \texttt{mmmm mmmm}, the mask, in hexadecimal notation.
\end{enumerate}

\noindent \textbf{Note:} The mask must not contain a ``1'' in the sign position, as the program ignores the sign of the key words.

\subsubsection*{OPERATION}
\begin{enumerate}
    \item \textbf{Execution time:} \\
    Examples:
    \begin{itemize}
        \item 64 single-word entries: 27 min. 15 sec.
        \item 32 two-word entries: 7 min. 25 sec.
    \end{itemize}
    \item \textbf{Program entry:} \\
    The tape contains the program in two versions:
    \begin{itemize}
        \item[a)] arbitrarily relocatable, hexadecimal, permissible for Program Input 1, and
        \item[b)] arbitrarily relocatable, decimal, in coding sheet format.
    \end{itemize}
    \item \textbf{Required input/output units:} \\
    No input or output units are required.
    \item \textbf{Overflow:} \\
    Ignored upon entry and not reset upon exit.
\end{enumerate}
