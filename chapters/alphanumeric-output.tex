\section{Alphanumeric Output}
\subsection{Alphanumeric Output 1}
\subsubsection*{J4-11.0}
\label{sec:alphanumeric-output-1}

\subsubsection*{PURPOSE}
Program J4-11.0 translates keywords and handles their output as alphabetic and/or numeric text. The alphanumeric text must be stored by the main program in a 4-bit character encoding format. It consists of a group of words composed of special codes corresponding to the characters and functions of the typewriter. The amount of data to be stored for J4-11.0 is limited only by the available memory space. The information must be stored in ascending sequence in consecutive memory cells.

J4-11.0 operates as a subroutine. It is called by a calling sequence in the main program. Before jumping to the subroutine, the starting address of the data block to be output must be stored within the subroutine. The memory locations following the jump instruction must contain the control keywords. Upon return to the main program, the output operation has already been executed.

\subsubsection*{MEMORY USAGE}
\begin{center}
\begin{tabular}{ll}
    \toprule
    Program storage & 56 sectors \\
    Buffer usage    & None \\
    \bottomrule
\end{tabular}
\end{center}

\subsubsection*{INPUT REQUIREMENTS}
The starting address of the keyword list must be stored before jumping to the subroutine. The data block must consist of consecutive words located immediately following the jump instruction of the calling sequence. Each word consists of four keyword symbols (encoded as pairs of characters), which correspond to alphabetic characters as well as the control functions of the typewriter.\footnote{This subroutine essentially encodes the Flexowriter's 6-bit characters as 8-bit ones, so that each character takes up two hex digits. Instead of having to bit-slice characters in one's head and attempt to pack them 5 to a word, this subroutine lets you pack them 4 to a word on hex-digit boundaries and not lose your marbles.} 

The last word of the block is designated by the special termination symbol \texttt{7Q}. Since every word must contain four keyword symbols (representing eight total hexadecimal digits per word), two to six trailing zeros are required to fill out the final word. The number of words in a block is limited only by available memory space. In the main program, every block of 63 or fewer keywords must be preceded by a hexadecimal loader control word, as required by Program Input 1.

\subsubsection*{EXAMPLE}
The following example illustrates how to compile a data group for ``Alphanumeric Output 1'':
\begin{center}
\begin{tabular}{cccll}
    \toprule
    \textbf{Loader Word} & \textbf{Location} & \textbf{Opcode} & \textbf{Address} & \textbf{Description} \\
    \midrule
                      & $x$               & \texttt{R}      & \texttt{L}       & Set data pointer. \\
                      & $x+1$             & \texttt{U}      & \texttt{L}       & Branch to subroutine. \\
    \texttt{.0000004} & $x+2$             & \texttt{20}     & \texttt{42 09 72}& Alphanumeric raw hex data tokens. \\
                      & $x+3$             & \texttt{32}     & \texttt{32 22 32}& Alphanumeric raw hex data tokens. \\
                      & $x+4$             & \texttt{5J}     & \texttt{06 42 72}& Alphanumeric raw hex data tokens. \\
                      & $x+5$             & \texttt{12}     & \texttt{7F 7Q 00}& Alphanumeric raw hex data tokens with end marker. \\
                      & $x+6$             & \dots           &                  & Main program resumes. \\
    \bottomrule
\end{tabular}
\end{center}

This example issues an automatic carriage return command, prints the text \texttt{"PLANNING PAYS"}, and cleanly branches execution back to location $x+6$ of the main program logic sequence. The token \texttt{7Q} inside the final memory word marks the structural end code statement; the remaining trailing zero characters are solely included to fill out the word boundary layout.

\subsubsection*{CALLING SEQUENCES}
There are two distinct calling sequences available for invoking ``Alphanumeric Output 1''. Calling Sequence 1 is utilized exclusively when routing output to the standard console typewriter. Calling Sequence 2 is used when an alternative hardware output peripheral unit is required.

\paragraph{Calling Sequence 1 (Standard Typewriter Output)}
\begin{center}
\begin{tabular}{ccll}
    \toprule
    \textbf{Location} & \textbf{Opcode} & \textbf{Address} & \textbf{Description} \\
    \midrule
    $x$               & \texttt{R}      & \texttt{L}       & Transfer starting address of data block into subroutine cell \texttt{L}. \\
    $x+1$             & \texttt{U}      & \texttt{L}       & Jump to subroutine standard execution entry point. \\
    $x+2$             & \dots           &                  & (First control keyword string token word). \\
    $\dots$           & \dots           &                  & Alphanumeric string control words. \\
    $x+n$             & \dots           &                  & (Final control keyword string token word containing \texttt{7Q}). \\
    $x+n+1$           & \dots           &                  & Main program execution resumes. \\
    \bottomrule
\end{tabular}
\end{center}
The instruction at location $x$ stores the entry pointer of the data block into the subroutine body. The command at $x+1$ triggers the execution branch. Cells $x+2$ through $x+n$ contain the $n$ string keyword words. Location $x+n+1$ holds the next instruction of the main program to be executed immediately following subroutine exit.

\paragraph{Calling Sequence 2 (Custom Peripheral Routing)}
\begin{center}
\begin{tabular}{ccll}
    \toprule
    \textbf{Location} & \textbf{Opcode} & \textbf{Address} & \textbf{Description} \\
    \midrule
    $x-1$             & \texttt{B}      & \texttt{[Code]}  & Load custom device selection control word into accumulator. \\
    $x$               & \texttt{R}      & \texttt{L}       & Store starting address of keywords into subroutine body. \\
    $x+1$             & \texttt{U}      & \texttt{L+50}    & Jump to alternative device-selection entry point. \\
    $x+2$             & \dots           &                  & (First control keyword string token word). \\
    $\dots$           & \dots           &                  & Alphanumeric string control words. \\
    $x+n$             & \dots           &                  & (Final control keyword string token word containing \texttt{7Q}). \\
    $x+n+1$           & \dots           &                  & Main program execution resumes. \\
    \bottomrule
\end{tabular}
\end{center}
This configuration differs from the standard entry pattern by exactly two operational instructions. The command at $x-1$ stages the peripheral selection mask inside the accumulator register. This selection code can be encapsulated within the track address operand field of a standard non-operative instruction word (e.g., \texttt{xZ tt00}, where \texttt{tt} represents the physical target peripheral selector code). The command at $x+1$ branches into the alternative subroutine device configuration entry sequence at offset address \texttt{L+50}.

\subsubsection*{OUTPUT CHARACTERISTICS}
Upon execution return to the main program context, the alphanumeric string array text generation sequence has been completely processed and sent to the printer hardware buffer.

\subsubsection*{OPERATING INSTRUCTIONS}
\begin{enumerate}
    \item \textbf{Execution Speed:} Throughput clocks at approximately 660 characters per minute.
    \item \textbf{Program Loading Instructions:} The routine tape distribution features the software in two alternate styles:
    \begin{enumerate}[label=\alph*)]
        \item Relocatable hexadecimal format compatible with Program Input 1.
        \item Relocatable decimal format mapped to the standard coding sheet structure.
    \end{enumerate}
    \item \textbf{Required Input/Output Units:} Hardware data input units are not required. If an alternative hardware peripheral unit other than the primary console typewriter is designated for text routing, the absolute track operational address entries inside memory cells \texttt{L+06}, \texttt{L+14}, \texttt{L+22}, and \texttt{L+30} of the subroutine body must be manually patched to match the system configuration constants (consult the \textit{LGP-21 Programming Manual} peripheral channel assignment tables for absolute unit selector byte lists).
    \item \textbf{Hardware Overflow Flag Status:} The register status is neither read nor impacted by this program's internal loop execution paths.
\end{enumerate}

\subsection*{ALPHANUMERIC OUTPUT 2 (J4-11.1)}

\subsubsection*{Purpose}
The program J4-11.1 outputs alphabetic and/or numeric information that has been stored without binarization (i.e., stored as raw character codes). The alphanumeric data must be stored as \textbf{five-character-long words in 6-bit format}. A data block for J4-11.1 must not exceed 63 cells. The data must be stored in consecutive memory cells.

The program operates as a subroutine called by a calling sequence from the main program. The starting address of the data block must be supplied to the subroutine before entry. Upon return to the main program, the specified information has already been printed.

\subsubsection*{Storage Requirements}
\begin{itemize}
    \item \textbf{Program Space:} 24 sectors
    \item \textbf{Temporary Storage:} None
\end{itemize}

\subsubsection*{Input}
Before jumping to the subroutine, the calling sequence must insert into the first cell of the subroutine the address of the \texttt{Z} instruction which contains the starting address of the alphanumeric data block to be printed. This makes it possible to store the data block at any arbitrary location in memory, instead of forcing it to immediately follow the calling sequence as is typical. This \texttt{Z} instruction must not be omitted.

The data table consists of consecutive words of exactly 5 characters or typewriter functions each (the final word may contain fewer). The number of words in a single block must not exceed 63. The data must be stored in ascending order in consecutive cells. 

During input storage, the data must be preceded by the constant keyword of \textbf{J1-10.0} so that it is not binarized. (The input keyword also automatically places an end-of-block marker ``into the final word'').

\paragraph{Example}
\begin{center}
\small
\begin{tabular}{lllll}
    \toprule
    \textbf{Program Input Keyword} & \textbf{Memory Location} & \textbf{Instruction} & \textbf{Address} & \textbf{Description} \\
    \midrule
    & $\alpha$ & \texttt{R} & \texttt{L} & Store return address \\
    & $+1$     & \texttt{U} & \texttt{L} & Entry to subroutine \\
    & $+2$     & \texttt{Z} & \texttt{AA} & Pointer to data block \\
    & $+3$     & u.s.w.     &             & Return to main program \\
    [1ex]
    \texttt{A0000003 A} & \texttt{AA} & \texttt{PLANN} & & First data word \\
    & $+1$     & \texttt{ING P} & & Second data word \\
    & $+2$     & \texttt{AYS}   & & Final data word \\
    \bottomrule
\end{tabular}
\end{center}

This example causes the printout of \texttt{PLANNING PAYS} and returns execution to $+3$ of the main program. The end-of-block marker is automatically stored by the program input keyword. The alphanumeric data can reside anywhere in memory.

\subsubsection*{Calling Sequence (J4-11.1)}
\begin{center}
\small
\begin{tabular}{llll}
    \toprule
    \textbf{Memory Location} & \textbf{Instruction} & \textbf{Address} & \textbf{Description} \\
    \midrule
    $\alpha$ & \texttt{R} & \texttt{L}  & Insert the address of the \texttt{Z} instruction ($+2$) into \texttt{L}. \\
    $+1$     & \texttt{U} & \texttt{L}  & Entry into the subroutine. \\
    $+2$     & \texttt{Z} & \texttt{A}  & Starting address of the data block ($A$). \\
    $+3$     & u.s.w.     &             & Return to the main program. \\
    \bottomrule
\end{tabular}
\end{center}

The instruction at $\alpha$ stores the address ($+2$) of the instruction containing the data block's starting address into the subroutine. The instruction at $+1$ executes a jump to the starting address ($L$) of the subroutine. Cell $+2$ contains the \texttt{Z} instruction with $A$, the starting address of the data block. Cell $\alpha+3$ contains the instruction of the main program that will be executed first after exiting the subroutine. 

\textit{Please note: The \texttt{Z} instruction must always reside directly within the calling sequence, even if the data block immediately follows the calling sequence.}

\subsubsection*{Output}
Upon return to the main program, the desired data block has already been output to the terminal.

\subsubsection*{Operation}
\begin{enumerate}
    \item \textbf{Time Required:} Approximately 190 characters per minute.
    \item \textbf{Program Input:} The tape contains the program in two versions:
    \begin{itemize}
        \item[\textbf{a)}] Arbitrarily relocatable hexadecimal (valid for Program Input 1).
        \item[\textbf{b)}] Arbitrarily relocatable decimal (in coding sheet format).
    \end{itemize}
    \item \textbf{Required Input/Output Units:} No input units are required. The standard typewriter is selected for output by default. If a different output unit is to be used, the track addresses in cells \texttt{L+03}, \texttt{L+05}, \texttt{L+07}, \texttt{L+09}, and \texttt{L+11} of the subroutine must be replaced with the corresponding selection identifier (see the \textit{LGP-21 Programming Manual}, where selection identifiers and their associated units are listed).
    \item \textbf{Overflow:} Neither tested nor altered by the program.
\end{enumerate}

\subsubsection*{Remarks}
The program should ideally begin at \textbf{Sector 00} to ensure optimal drum execution timing.
